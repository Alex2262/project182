PROJECT182 — LONGER RUNS AND THREE TRAINING SEEDS

Completed: four architectures × three independent training seeds, each at 10,000 steps, on the same noisy d=5 linear-regression task. Each checkpoint at 2k, 5k, and 10k was evaluated on the same fresh 1,024-prompt confirmation set after all training decisions were fixed.

WHAT THIS ADDS TO THE FIRST PILOT
The Transformer’s mean confirmation error fell from 0.5237 to 0.0527, roughly a tenfold reduction. Gated DeltaNet had the lowest final error in every seed. Transformer and Mamba-2 are close overall: their paired three-seed difference has a wide 95% interval spanning zero, so these runs do not establish a reliable winner between them.
At 32 context examples, Mamba-2’s normalized shuffle sensitivity averaged 0.0435 versus 0.1945 for the Transformer; Gated DeltaNet averaged 0.0211. Prediction quality and order sensitivity provide different information. These are descriptive findings on this control task, not causal evidence about the learned algorithm.
The 2,000-step comparison was strongly affected by learning speed. The table above compares identical held-out prompts across every checkpoint and seed, so improvements are not caused by using an easier test set for the longer runs.
10,000 steps is a common training budget, not a guarantee of convergence. We chose this horizon after reviewing the original seed’s validation curves, then fixed it before launching the two additional seeds. Some validation curves were still improving. The confirmation set was not used for learning-rate selection, horizon selection, or early stopping.
Three seeds allow a preliminary repeatability assessment. Detailed results include Student-t 95% intervals for seed means and paired architecture differences, but with only three seeds those intervals have limited precision and assume a suitable sampling model. Main figures show individual seeds and one-SD error bars explicitly.
This remains a low-dimensional control, not evidence of a state-capacity threshold. There is no state-size or task-difficulty intervention. Models share depth and width but differ in parameter counts, normalization details, and local convolutions. Linear attention has no short convolution. Persistent gaps can still reflect optimization or input/label binding.

EXPERIMENT PROTOCOL
Learning rate 3e-4, Adam, no weight decay, gradient-norm clipping at 1, batch 64, width 128, four layers and four heads, 33 x/y pairs per prompt. Gaussian N(0,I) weights; uniform [-1,1]^5 inputs; additive noise std 0.5. Fresh training prompts at every update. Full FP32 with PyTorch TF32 disabled. The original seed resumed its saved optimizer and RNG states; new seeds varied both initialization and the training stream.
Training seeds: 182, 183, 184. Data-stream seeds: 1,000,000; 2,000,000; 3,000,000. Within each seed, every architecture receives identical training prompts at each update. Validation seed 100,000,000 (256 prompts); confirmation seed 300,000,000 (1,024 prompts). Exact posterior means, Bayes risks, and effective dimensions are computed in float64.
Mean confirmation Bayes risk: 0.543575. Mean effective dimension at 32 observed examples: 4.8653. Zero-prediction normalized excess: 2.5869.
The model, task sampler, and metric implementations were verified byte-for-byte unchanged from the first pilot. The existing causal leakage, finite-gradient, checkpoint, optimizer-resume, Bayesian-reference, and delta-recurrence checks therefore continue to apply to the same implementations. Follow-up changes add seeds, milestone checkpoints, orchestration, and reporting. New source syntax and file-diff checks passed. All five exported figures were visually inspected.
Mamba-2 uses FLA’s PyTorch fallback; Gated DeltaNet uses an exact PyTorch triangular-solve recurrence. Linear attention uses its quadratic causal form. Measured execution time is not an optimized-kernel architecture benchmark.

NEXT SCIENTIFIC QUESTIONS
Before interpreting residual gaps as memory limits, establish sufficiently stable training and test an input-pairing control for plain linear attention. Then compare low- versus high-difficulty GP tasks and vary recurrent state size. For the forgetting hypothesis, compare i.i.d. and ordered-time prompts and use targeted gate interventions; gate averages alone cannot establish a causal mechanism.
